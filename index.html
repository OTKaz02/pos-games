The "771" Project — A Collaborative Experiment

In 2025, POS Games united 7 indie developers from across the globe to create "771" — an experimental horror anthology where each developer designed one segment with complete creative freedom. The result is a disorienting, genre-defying experience that blurs the line between authorship and nightmare.
